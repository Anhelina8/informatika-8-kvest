# 💻 Місія: врятувати алгоритм

### Інтерактивний навчальний квест з інформатики для учнів 8 класу НУШ

**Тема:** Етапи розв'язування задач.

## 📚 Про проєкт

«Місія: врятувати алгоритм» — це інтерактивний навчальний вебквест, створений для закріплення знань учнів 8 класу з теми «Етапи розв'язування задач» (розділ 4 «Алгоритми та програми»).

У форматі захопливої цифрової гри учні проходять п'ять рівнів, виконують завдання, перевіряють свої знання та отримують підсумковий результат.

## 🎯 Мета квесту

- Закріпити знання про основні етапи розв'язування задач.
- Навчити визначати умову задачі, вхідні та вихідні дані.
- Формувати навички побудови інформаційних і математичних моделей.
- Розвивати алгоритмічне та логічне мислення.
- Формувати вміння аналізувати результати та знаходити помилки.

## 🎮 Структура квесту

1. **Розшифруй умову** — визначення етапу постановки задачі.
2. **Побудуй модель** — вибір правильної математичної моделі.
3. **Віднови алгоритм** — установлення правильної послідовності етапів.
4. **Знайди помилку** — перевірка розуміння тестування програм.
5. **Фінальний запуск** — аналіз отриманих результатів.

## ⭐ Можливості

- Інтерактивні завдання з вибором відповідей.
- Відновлення правильної послідовності дій.
- Автоматична перевірка відповідей.
- Нарахування балів.
- Відображення результатів проходження.
- Можливість повторного проходження квесту.

## 🛠 Технології

Проєкт створено з використанням:
